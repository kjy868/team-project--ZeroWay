# ♻️ ZeroWay
> 인천 지역 기반 **제로웨이스트 지도 & 가이드** 웹사이트  
> 5R(Refuse/Reduce/Reuse/Recycle/Rot) 실천을 돕고, 친환경 소비를 더 쉽게 만드는 팀 프로젝트입니다.

## 🔗 Demo
- Site: https://zeroway.netlify.app/
- Repo: (깃허브 URL 넣기)

## ✨ Overview
ZeroWay는 제로웨이스트를 처음 시작하는 사람도 가까운 실천 장소를 빠르게 찾고,  
생활 속 친환경 행동을 **가이드 + 지도 경험**으로 자연스럽게 이어지도록 설계했습니다.

## ✅ Key Features
- 인천 중심 제로웨이스트 스팟 **지도/리스트 탐색**
- 5R 원칙 소개 및 실천 가이드
- 실행중인 정책과 원데이클래스 등 안내
- 사용자 참여형 제보하기 페이지
- CO₂ 절감 등 인포그래픽 콘텐츠

## 🧩 Tech Stack
- HTML / SCSS / JavaScript / jQuery
- 사용한 라이브러리: GSAP
- Deploy: Netlify
